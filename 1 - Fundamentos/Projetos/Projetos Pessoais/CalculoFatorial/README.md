# Cálculo de Fatorial - Kevyner Ramalho
Projeto de terminal que dá ao usuário poder calcular o fatorial de um número em um loop que ele decide quando quer terminar o programa

## Conhecimentos Utilizados no projeto
- Condicionais (If, Else, Else, If)
- Static
- Estruturas de Repetição(For, While)
